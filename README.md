# Atlas of Life

A visual, fully sourced encyclopedia of life on Earth, organised as a tree of life.
Pilot volume: **Pterosauria** — 126 genera, 21 clades, 72 excluded names.

Every genus entry lists its species, age range, geological formations, known fossil material,
biology, credited images (Wikimedia Commons, PhyloPic; no AI images), a size comparison with a
1.8 m human, and its sources. The site has two linked modes: an **Encyclopedia** (entries, index,
timeline) and a **Tree of life** outline of the whole classification.

## Quick start

Needs Python 3.10+ with PyYAML (`pip install pyyaml`) and, for the visual test, Chrome/Chromium.

```bash
python3 scripts/build.py          # entries/ → site/data.json, site/life.json
python3 scripts/validate.py       # must report 0 errors
python3 -m http.server -d site 8000   # open http://localhost:8000
python3 tests/screenshots.py      # screenshots of every view in tests/out/
```

## How to contribute (also with Claude)

The rules for entries and the step-by-step workflow are in **[CLAUDE.md](CLAUDE.md)**.
In short:

```
request → branch → edit entries/*.yaml or site/ → fmt → build → validate → screenshots
        → review diff → commit → report → merge & push
```

Current phase: **consolidating Pterosauria**. See [docs/CONSOLIDATION.md](docs/CONSOLIDATION.md)
(generated by `python3 scripts/validate.py --report`) for the open issues, and
[docs/DECISIONS.md](docs/DECISIONS.md) for why things are the way they are.

## Layout

```
entries/pterosauria/   genera/*.yaml, clades/*.yaml, excluded.yaml, _volume.yaml  ← edit these
data/tree/             backbone of the tree of life (non-entry nodes)
data/raw/              raw downloads (PBDB, Wikipedia, Commons, PhyloPic) — provenance
scripts/               build.py, validate.py, fmt.py, legacy/ (prototype)
site/                  static website (index.html, css/, js/, img/, sil/, vendor/)
tests/                 screenshots.py
docs/                  QUEUE.md (clade work queue, generated), CONSOLIDATION.md (generated), DECISIONS.md
```

## Publishing

`site/` is a static site: any static host works (GitHub Pages: publish the `site/` folder).
