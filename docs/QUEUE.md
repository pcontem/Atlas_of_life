## How Claude works from this list (so the owner does not need the chat history)

1. Read `CLAUDE.md` (§3, §4.2b, §5) and **only this file** — no earlier conversation is needed.
2. Take the **first 10 unchecked** clades under “Next batch” (or the number the owner names). Skip none; a parent comes before its children.
3. For each: write `entries/tree/clades/<id>.yaml` as in §4.2b (sources from `data/raw/tree/clade_sources_*.json` / `clade_refs_*.json`; if the clade is not there, fetch its fixed Wikipedia revision and PBDB record). Never invent facts; doubts go to `curation.notes`.
4. Place genera and fix the structure of the group from recent cladograms before writing its children (§4.8; record changes in `docs/TREE_REVIEW.md`). Informal groupings get no entry.
5. `python3 scripts/fmt.py && python3 scripts/build.py && python3 scripts/validate.py` → 0 errors; look at the screenshots of one new entry.
6. `python3 scripts/queue.py` (ticks the finished items), one commit per batch on a branch `entry/queue-<first-id>`, report to the owner. Never mark `checked`.
